## About the Script

Welcome to Bloxburg Script provides Roblox players on PC with a focused set of tools for frequently used in-game activities. The utility brings together aim assistance, automated item collection, and hotkey-driven switches, allowing individual functions to be enabled or disabled as needed.

Its design prioritizes a compact runtime profile without removing useful behavior controls. Collection distance can be tuned, aiming can be smoothed, and hotkeys can be assigned to match different preferences or play styles. These controls also make the script easier to adapt across game and build updates.

## Available Features

- Aim assistance through the included aimbot module
- Automated collection for supported items or resources
- On-demand toggles for switching individual functions on or off
- Smooth aim transitions for more gradual movement
- Adjustable collection radius for controlling pickup distance
- Remappable hotkeys for personalized feature access
- Session persistence for retaining selected options while in use
- Lightweight execution intended to keep the running utility compact

## PC Compatibility

The script is made for Welcome to Bloxburg sessions on Roblox using a PC. Actual behavior can depend on the executor in use, changes introduced by game updates, and modifications to the systems involved in aiming or collection.

Current limitations include:

- Intended for PC rather than mobile-oriented use
- A compatible executor is required to load the script
- Updates may require some hotkeys to be assigned again
- Changes to the game can influence feature operation and session persistence

## Frequently Asked Questions

**What is the loading process?**  
Run the script through a compatible PC executor while you are inside Welcome to Bloxburg.

**Are the hotkeys editable?**  
Yes. The included hotkey settings let you assign feature toggles to the keys you prefer.

**How are future builds handled?**  
The project uses versioned releases, allowing a newer build to replace the current one when it becomes available.

**Can the collection distance be changed?**  
Yes. Adjust the collection radius to control the range used by the auto-collect function.

**How long do my settings remain available?**  
Session persistence allows chosen settings to stay active during the current run, subject to the behavior of the build and executor.
